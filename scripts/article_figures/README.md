# Article-figure before/after workflow

This workflow compares the legacy and corrected scientific content of Figures
1-16 from *Lorenz Energy Cycle Climatology for the Southwestern Atlantic
Cyclones*. It writes products under
`figures/lec_climatology_corrected/`, `results/lec_climatology_corrected/`, and
`docs/`; it never overwrites the published legacy products.

## Inputs and scope

- Legacy phase-mean cache, restricted to the 3,820 corrected cyclones.
- Corrected phase-mean cache: 3,820 cyclones and 15,829 period rows.
- Frozen South Atlantic tracks: positions, timestamps, and 850-hPa vorticity.
- Main-article panels: exactly one primary `incipient`, `intensification`,
  `mature`, and `decay` record per cyclone (15,280 rows).
- Secondary lifecycle periods remain in the source cache for provenance but do
  not enter the four-phase figures.

Both versions contain exactly the same 15,280 primary cyclone-phase keys. EOFs
use the published 24 LEC variables and a correlation matrix; corrected modes
are matched to legacy modes by maximum absolute pattern correlation and
sign-aligned. Intense systems use the published pointwise 90th-percentile
vorticity criterion and six clustering terms. Corrected clusters are matched to
legacy clusters by minimum standardized centroid distance.

## Generate Figures 1-16

Run on `swell`, where the corrected cache and track database live. The current
server `base` environment contains both `pyarrow` and `cartopy`; a newly created
repository environment from `environment.yml` is equivalent:

```bash
conda run -n base python scripts/article_figures/generate_comparison.py \
  --legacy-cache /p1-swell/danilocs/paper_energy_patterns/data/energy_cache.parquet \
  --corrected-cache /p1-swell/danilocs/paper_energy_patterns/data/corrected/energy_cache_corrected.parquet \
  --tracks /p1-swell/danilocs/paper_energy_patterns/data/tracks_SAt_filtered_with_energetics_processed.csv \
  --output-root /p1-swell/danilocs/lec-climatology-rerun
```

The command exports every figure as a 300-dpi PNG and vector PDF. Figure 16 is
split into 16a-d, one 1x2 before/after panel per EOF, so the manifest contains
19 files for the 16 main figure numbers. It also writes paired EOF diagnostics,
PC-extreme assignments, matched intense-cluster assignments, summary
statistics, and input/output hashes.

## Build the consolidated report

After generating the figures:

```bash
python scripts/article_figures/build_report.py --output-root "$PWD"
```

The output is `docs/lec_climatology_corrected_figures_report.pdf`. The adjacent
Markdown file is generated by the figure workflow and embeds the same 19 PNGs.

## Reproducibility checks

```bash
pytest -q tests/test_article_figures.py
```

Check `results/lec_climatology_corrected/provenance.json` for input hashes and
the pinned toolkit commits, and `figure_manifest.csv` for output checksums.
