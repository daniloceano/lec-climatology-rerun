# Article results

The article has three result families:

- `original/article/`: published reference products, plus a passed reproduction gate in `reproduction_gate/`. The top-level total EOF scores, extreme assignments and four-cluster tables come from that gate.
- `corrected/article/`: validated corrected numerical products for Figures 1–16 and Table 1. Figures 5–8 use the matched phase EOFs; Figures 9–16 use the gate-first corrected workflow. `figure_manifest.csv` covers all 16 figures; `figure_manifest_09_16.csv` records the eight figures regenerated by the downstream script.
- `comparison/article/`: versioned `before`/`after` tables and the 16 published-versus-corrected figure hashes. `phase_eof_matched/` contains the shared phase EOF definitions for Figures 5–8.

The legacy population has 6,789 cyclones, with 679 intense systems in four clusters. The corrected population has 3,820 cyclones, with 603 intense systems in four clusters. Both versions of the total EOF and clustering tables are assembled from the corresponding validated result families by `python -m scripts.article_figures.build_article_results`.

To regenerate Figures 9–16 and their numerical products, run `python -m scripts.article_figures.reproduce_downstream`, then `python -m scripts.article_figures.build_article_results`, then `python -m scripts.article_figures.build_validated_comparison`. Table 1 is generated with `python -m scripts.article_figures.generate_corrected_article_table`. Each family has a `provenance.json` with hashes.

`comparison/paired_control/` contains separate correction-only diagnostics for a fixed 3,820-cyclone population; it is not the article-population comparison.
